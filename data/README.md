# Data

The data come from the [Human Mortality Database](https://www.mortality.org/) (Sweden, 1×1 format). The HMD user agreement does not allow the data to be redistributed, so the files are not included in this repository.

Download these three files (free registration) and place them in this folder:

- `Mx_1x1.txt`: central death rates
- `Deaths_1x1.txt`: death counts
- `Exposures_1x1.txt`: exposures to risk
